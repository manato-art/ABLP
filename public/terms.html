AB Creative

利用規約

Cypher One 株式会社

第1条（適用）

  1. 本利用規約（以下「本規約」といいます）は、Cypher One 株式会社（以下「当社」といいます）が提供する「AB Creative」（以下「本サービス」といいます）の利用条件を定めるものです。
  2. 本規約は、本サービスを利用するすべての利用者（以下「ユーザー」といいます）に適用されます。
  3. ユーザーは、本サービスを利用する前に、本規約およびプライバシーポリシーに同意するものとします。

第2条（サービス内容）

  1. 本サービスは、AIを用いて広告バナー、広告文、クリエイティブ案その他広告制作に関連する成果物の生成・編集・管理を支援するサービスです。
  2. 本サービスは、広告表現の合法性、媒体審査通過、CPA改善、売上向上、その他特定成果を保証するものではありません。
  3. 当社は、本サービスの内容、仕様、機能、料金プラン、提供条件を、必要に応じて変更できるものとします。

第3条（アカウント登録）

  1. ユーザーは、当社所定の方法によりアカウント登録を行うものとします。
  2. ユーザーは、自らが満18歳以上の自然人または法人であることを表明し保証します。
  3. ユーザーは、登録情報について、真実、正確かつ最新の情報を提供するものとします。
  4. ユーザーは、アカウントを第三者に貸与、譲渡、共有してはなりません。
  5. 当社は、虚偽登録、不正利用、なりすまし、競合調査目的、その他当社が不適切と合理的に判断した場合、アカウント停止、契約解除、利用制限等を行うことができます。

第4条（個人向け無料トライアル）

  1. 個人ユーザーは、7日間の無料トライアルを利用できます。
  2. 無料トライアル期間中の生成可能枚数は最大50枚までとします。
  3. 個人ユーザーが無料トライアル期間終了前までに解約しない場合、無料トライアル終了日の翌日（8日目）に、HUSTLEプラン（月額9,800円・税込10,780円）へ自動移行し、登録済み決済手段へ自動請求されます。
  4. 当社は、無料トライアル終了日の少なくとも3日前までに、課金予定日をメール等で通知します。
  5. 無料期間中は、いつでも解約可能です。

第5条（法人向け無料トライアル）

  1. 法人ユーザーは、会社情報、担当者情報その他当社所定情報を提出することで、法人向け無料トライアルを申し込めます。
  2. 当社は、審査の結果、トライアル提供を拒否または停止できます。
  3. 法人向け無料トライアルでは、当社が別途明示する場合を除き、自動課金は発生しません。

第6条（料金および決済）

  1. 本サービスの料金は、当社ウェブサイト、申込画面、見積書その他当社所定画面に表示します。
  2. 決済は、Stripe Japan株式会社が提供する決済システムを通じて行われます。
  3. 当社は、クレジットカード情報を直接保持しません。
  4. 有料プランは、ユーザーが解約しない限り、契約期間満了時に自動更新されます。
  5. 月額料金は以下のとおりです。
    • HUSTLE：月額9,800円（税込10,780円）
    • FLEX：月額50,000円（税込55,000円）
    • GOAT：月額120,000円（税込132,000円）
    • Enterprise：個別見積
  6. プランごとに生成上限枚数が設定されます。
  7. 超過課金にユーザーが同意した場合、追加生成について従量課金が発生します。

第7条（解約）

  1. 個人ユーザーは、本サービス内の解約手続ページからいつでも解約できます。
  2. 解約は、現在の契約期間満了時に効力を生じます。
  3. 解約後も、契約期間満了時までは利用できます。ただし、当社は、セキュリティ保護、システム運用、プラン制御その他合理的理由に基づき、一部機能制限、生成停止、保存容量制限その他必要制限を行う場合があります。
  4. 期間満了後、新規生成・編集等の有料機能は利用できません。
  5. 既に支払われた料金について、日割返金は行いません。
  6. 解約とアカウント削除は別手続です。
  7. アカウント情報、履歴、プリセット等は最大12か月保持される場合があります。
  8. 完全削除を希望する場合、ユーザーはサポート窓口へ申請するものとします。

第8条（入力データおよび生成データ）

  1. 入力データの権利は、ユーザーまたは正当権利者に帰属します。
  2. 生成データについて、法令上認められる範囲で、ユーザーに利用権が帰属します。
  3. 当社は、生成データについて、独占的権利、著作権発生、第三者権利非侵害性、独自性その他を保証しません。
  4. AI生成の性質上、第三者が類似または同一生成結果を取得する可能性があります。
  5. ユーザーは、入力データについて必要権利を取得済みであることを保証します。

第9条（データ利用）

  1. 当社は、サービス提供、品質向上、障害解析、研究開発、不正利用防止等のため、入力データ、生成データ、利用ログ等を利用できます。
  2. 当社は、入力データまたは生成データそのものを、第三者広告素材として販売しません。
  3. 当社は、識別不能加工した統計情報等を、研究開発、営業分析、M&A、事業開発等に利用できます。
  4. 法人ユーザーその他当社が認めるユーザーは、AIモデル学習利用除外を希望する場合、個別協議を申し出ることができます。
  5. 当社は、技術的実現可能性、運用制約等を踏まえ、合理的範囲で対応します。

第10条（広告表現等に関する責任）

  1. 本サービスは広告制作支援ツールです。
  2. ユーザーは、生成物利用前に、薬機法、景品表示法、特定商取引法、著作権法、商標法、媒体審査基準等への適合性を自己責任で確認するものとします。
  3. 当社は、媒体審査通過、CPA改善、CV増加、売上向上等を保証しません。
  4. 最終的な広告出稿判断は、ユーザー自身が行うものとします。

第11条（禁止事項）

ユーザーは以下を行ってはなりません。

  1. 法令違反行為
  2. 権利侵害行為
  3. 虚偽・誇大広告生成
  4. 薬機法等違反表現生成
  5. 無断人物画像利用
  6. 無断商標利用
  7. アカウント共有
  8. スクレイピング、クローリング、ボット利用
  9. 内部API直接アクセス
  10. リバースエンジニアリング
  11. 類似サービス開発
  12. セキュリティ回避
  13. 第三者AI学習利用
  14. RAG、embedding、蒸留、fine-tuning、synthetic training等への利用
  15. 管理画面、未公開機能、内部仕様等を無断でSNSその他へ公開する行為
  16. その他当社が不適切と判断する行為

第12条（違反時措置）

  1. 当社は、違反時、以下措置を行えます。
    • ① アクセス遮断
    • ② アカウント停止
    • ③ データ削除
    • ④ 決済停止
    • ⑤ 法令上許容範囲での違反概要公表
  2. 当社は、損害賠償請求法的措置、警察通報等を行う場合があります。

第13条（免責）

  1. 当社は、本サービスの完全性、正確性、継続性、適法性を保証しません。
  2. AI生成物には、誤情報、第三者権利侵害可能性、不正確内容が含まれる場合があります。
  3. ユーザーは、利用前に自己責任で確認するものとします。
  4. 当社の損害賠償責任は、過去12か月利用料金総額を上限とします。
  5. 消費者契約法その他強行法規に従います。

第14条（事業承継）

当社は、M&A、事業譲渡等に伴い、契約上地位、ユーザー情報等を承継先へ移転できるものとします。

第15条（規約変更）

  1. 当社は、合理的理由に基づき本規約を変更できます。
  2. 不利益変更時は、30日前までに通知します。
